📖 Instrucciones para obtener tu Token de GitHub:

  1. Ve a github.com/settings/tokens
  2. Click en "Generate new token" → "Generate new token (classic)"
  3. Selecciona los permisos: repo (para poder editar archivos)
  4. Genera el token y cópialo (guárdalo, solo lo verás una vez)
  5. Pega el token aquí junto con tu nombre de usuario y repositorio
